# Roadmap

## Near term

- Add playing-time or set-count exposure when a permitted source is available.
- Add competition-strength and home/away context.
- Add walk-forward cross-validation and interval calibration.
- Add model-registry integration and data-drift reports.

## Model candidates

- Gradient-boosted regression as a strong small-data benchmark.
- Temporal convolutional network.
- Hierarchical partial-pooling model across athletes with position embeddings.
- Quantile loss for directly estimated prediction intervals.

## Data work

- Stable athlete/team identity mapping across seasons.
- Explicit competition and rule-version fields.
- Source-schema snapshots and contract-change alerts.
